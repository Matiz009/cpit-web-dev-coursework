# CPIT Web Development Coursework

Exercises and mini-projects from a web development course, moving from HTML basics to an Express + MongoDB backend and a React frontend.

## What's inside

| Folder | Contents |
|---|---|
| `basics-html/`, `css/` | HTML and CSS fundamentals |
| `bootstrap/`, `tailwind/` | UI with Bootstrap and Tailwind CSS |
| `js/`, `functions/`, `events/`, `async/` | JavaScript, DOM events (bubbling and delegation guide), async code |
| `node/` | Node.js basics |
| `express/` | Express + MongoDB (Mongoose) API with user and post controllers, and password hashing |
| `frontend/` | React + Vite frontend |

## Tech stack

HTML · CSS · Bootstrap · Tailwind CSS · JavaScript · Node.js · Express · MongoDB · React · Vite

## Getting started

Static exercises: open any `index.html` in a browser.

API:

```bash
cd express
npm install
node index.js
```
